# Recipes

Patterns for setups the kit does not install by default. Optional ones stay off until a Being needs them.

| Recipe | For |
|---|---|
| [two-boxes-one-being.md](two-boxes-one-being.md) | One Being on a second machine without forking it |
| [llm-proxy.md](llm-proxy.md) | Local model proxy with backup keys and per-app virtual keys (optional) |
| [owner-device-sync.md](owner-device-sync.md) | Daily fast-forward sync of the owner's laptop, failure-only report (optional) |
| [boot-guard.md](boot-guard.md) | Keep the box booting after power cuts (optional) |
| [remote-desktop.md](remote-desktop.md) | Pointer to the desktop skill and its cleanup rules |
| [tester-link.md](tester-link.md) | Temporary tester link with access first and scheduled teardown (optional) |
| [project-service-unit.md](project-service-unit.md) | A project app as a user unit with its own env file |
